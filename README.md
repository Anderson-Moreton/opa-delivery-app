# Opa Food

Sistema de delivery desenvolvido com Angular, Node.js, Express, MySQL e Stripe.

# Projeto Integrador 

Figma: https://www.figma.com/file/XQJdAmq4x7CK38fIJGB6kH/Projeto-Integrador?node-id=0%3A1

## Funcionalidades

* Cadastro e login de usuários
* Carrinho de compras
* Finalização de pedidos
* Pagamento com cartão via Stripe
* Pagamento PIX via Stripe
* Histórico de pedidos
* Painel administrativo
* Dashboard de vendas

## Tecnologias

### Frontend

* Angular
* TypeScript
* CSS

### Backend

* Node.js
* Express
* TypeScript

### Banco de Dados

* MySQL

### Pagamentos

* Stripe Card Payments
* Stripe PIX

## Como executar

### Backend

```bash
npm install
npm run dev
```

### Frontend

```bash
npm install
ng serve
```
